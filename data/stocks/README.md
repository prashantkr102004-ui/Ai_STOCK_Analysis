# Stock Data

Place local historical stock CSV files in this folder.

Expected format:

```csv
Date,Open,High,Low,Close,Volume,Symbol
2024-01-01,100,105,98,103,500000,TEST
2024-01-02,103,108,101,107,620000,TEST
```

`sample_stock.csv` is demo data for development only. Replace or add CSV files here when using real historical datasets.
